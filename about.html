About

Gunner Castle Entertainment is a software and web engineering studio. We build custom websites and custom software for people and businesses that need something built specifically for them.

We work across the stack, from websites and web apps to bespoke tools, automation, and bots that run behind the scenes. Whatever the project, the goal is the same: software that fits the way you actually work.

We build with languages and tools like Python, JavaScript, C, and Rust, and we're always picking up whatever the job calls for. No bloated templates, no one-size-fits-all, just software built to fit.
