# gce

Website for **Gunner Castle Entertainment LLC**, a software and web engineering studio building custom websites and custom software.

Live at **[gce.gunnercastle.com](https://gce.gunnercastle.com)**.

## Stack

- Static HTML / CSS / vanilla JavaScript
- Hosted on GitHub Pages (deployed via GitHub Actions)
- JetBrains Mono + system fonts, dark terminal-inspired theme

## Pages

- `index.html`: Home
- `services.html`: Services (custom websites, custom software, web apps, maintenance & hosting)
- `about.html`: About
- `contact.html`: Contact
- `privacy.html`: Privacy policy

## Local preview

Open `index.html` in a browser, or run a static server:

```sh
python3 -m http.server
```
